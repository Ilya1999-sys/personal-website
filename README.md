# Портфолио Ильи Поликарпова

Статический сайт без серверной части: HTML, CSS и JavaScript. Кейсы хранятся в `content/cases.json`, остальные данные — в `scripts/data.js`; изображения и локальные шрифты — в `images/` и `fonts/`.

## Локальный просмотр

Из папки `website` запустить:

```sh
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Cloudflare Pages

В настройках проекта оставить framework preset `None`, build command пустой и build output directory `.` (корень подключённого репозитория). Отдельный сервер для сайта не нужен.

После покупки домена его можно добавить в настройках Pages в разделе Custom domains и обновить DNS у регистратора. Домен покупается отдельно от хостинга.

## Админка кейсов

Для управления кейсами используется [Pages CMS](https://app.pagescms.org/). Конфигурация находится в `.pages.yml`. В админке можно менять заголовок, описание, обложку, ссылку, выбирать категории для фильтров и добавлять до пяти тегов. Сохранение создаёт коммит в GitHub; Cloudflare Pages затем автоматически публикует изменения.

Чтобы включить админку, войдите в Pages CMS через GitHub и установите Pages CMS GitHub App только для репозитория `Ilya1999-sys/personal-website`. После выдачи доступа откройте репозиторий в CMS — раздел «Кейсы» появится из конфигурации.
