# Портфолио Ильи Поликарпова

Статический сайт без серверной части: HTML, CSS и JavaScript. Кейсы, фильтры и ссылки находятся в `scripts/data.js`; изображения и локальные шрифты — в `images/` и `fonts/`.

## Локальный просмотр

Из папки `website` запустить:

```sh
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Cloudflare Pages

Для подключения Git-репозитория выбрать `None` как framework preset, оставить build command пустой и указать `.` как build output directory. Корневая папка проекта — `website`. После появления репозитория этот каталог можно подключить к Pages; отдельный сервер для сайта не нужен.

После покупки домена его можно добавить в настройках Pages в разделе Custom domains и обновить DNS у регистратора. Домен покупается отдельно от хостинга.
